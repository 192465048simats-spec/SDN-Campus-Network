📌 About the Project

This project provides a centralized SDN-based campus network monitoring system. It allows network administrators to observe network performance, monitor link utilization, detect congestion and identify the recommended traffic path.

🎯 Project Objectives

  • Monitor network performance in real time.
  • Track throughput, latency and packet loss.
  • Monitor active network connections.
  • Detect high link utilization.
  • Support QoS and traffic prioritization.
  • Provide dynamic path selection.

📊 Network Monitoring

The monitoring module continuously receives network information from the Flask backend. The dashboard displays throughput, latency, packet loss, active connections and link utilization.

⚡ QoS & Load Balancing

Quality of Service is used to prioritize important traffic such as VoIP and video. When a primary link becomes congested, the system can select an alternate path to improve traffic distribution.

🔐 Cybersecurity

The system improves security visibility by continuously monitoring network conditions, detecting abnormal utilization and providing security-oriented network status information.

🌐 SDN Network Topology

The simulated campus network contains multiple switches and communication paths. The SDN approach allows network traffic decisions to be centrally managed.

🛠 Technologies Used

HTML CSS JavaScript Python Flask REST API SDN ReportLab

📄 Reporting System

The system generates a detailed five-page PDF report containing network performance, topology, link utilization, QoS, cybersecurity assessment, recommendations and conclusion.
